## Custom Domain

Custom domain `briankipkemboi.com` is configured via the `CNAME` file and Namecheap DNS.

1. Update the `CNAME` file with your domain
2. Add these DNS records at your registrar (Namecheap):
   - `A` record → `185.199.108.153`
   - `A` record → `185.199.109.153`
   - `A` record → `185.199.110.153`
   - `A` record → `185.199.111.153`
   - `CNAME` record: `www` → `briankipkemboi.github.io`
3. Enable "Enforce HTTPS" in GitHub Pages settings
